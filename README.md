# 熄屏幻术 FadeCraft

按电源键熄屏的那一刻，不该只是一黑了之。

这个模块接管系统熄屏的最后一帧：先实时截一张当前画面，再把它拆成碎片、像素、灰烬或者微粒，播完一段动画之后才交给系统真正睡眠。

> ⚠️ **安装或更新本模块后，必须「整机重启手机」才能生效（当前版本 1.0.5）。** 应用内的「重启作用域」只会重启 SystemUI 和系统设置，**碰不到 system_server**——而拦截电源键、触发动画的核心逻辑正好在 system_server 里。所以只点「重启作用域」时，电源键动画不会出现；请直接重启手机。

- 8 种特效，颗粒大小、时长等参数可调
- 播放过程没有常驻服务，不做后台轮询
- 注入**系统框架（system_server）、SystemUI、系统设置**三个进程；电源键拦截发生在 system_server，所以更新后必须**整机重启**才会生效
- 出问题时设置页最底部可以一键**导出日志**（不需要 root），比截图管用

> **1.0.5 修的是「熄屏后那一秒」**：抓帧改成向 WindowManager 直接要一帧
> （`IWindowManager.captureDisplay`，Android 16/17 上不再受镜像抓屏权限收紧的影响，
> 耗时从 ~85ms 降到 ~30ms）；动画播完不再闪一下壁纸；指纹 / 人脸识别解锁的震动也回来了。
> 详见 [发布说明](NOTES-1.0.5.md)。

## 特效

| 特效 | 效果 |
|---|---|
| 碎屏 | 从按压点散开的裂纹，碎片带重力坠落 |
| 像素消散 | 画面碎成像素块，随机抖动后缩小消失 |
| 百叶窗 | 横向切条错位滑出 |
| CRT 关机 | 画面纵向压扁成一条亮线再熄灭 |
| 灰烬升腾 | 颗粒化后向上飘散，带火星余辉 |
| 风沙吹散 | 整体被风吹向一侧，带倾斜 |
| 条带垂落 | 竖向长条依次失重下落 |
| 崩解成尘 | 一道斜波从右下扫到左上，扫过处化为微粒飞散 |

每种特效都有独立的参数页：颗粒大小、时长、坠落距离等，改完立刻生效，可以用设置页里的「预览」先看不按电源键的效果。

## 安装

1. 手机已 Root，并装好 **LSPosed**（Magisk / KernelSU / APatch 均可）
2. 安装本模块 APK
3. 打开 LSPosed 管理器 → 模块 → 启用「熄屏幻术」
4. **作用域勾选「系统框架 / SystemUI / 系统设置」**（三个都勾：电源键拦截在系统框架 system_server，截屏与动画在 SystemUI，设置首页入口在系统设置；缺一个就会有功能不生效）
5. **整机重启手机**（关键）：应用内的「重启作用域」只重启 SystemUI + 系统设置、碰不到 system_server，所以**必须整机重启**才能让电源键动画生效
6. 打开模块的设置页，选一种动画，点「预览」确认有效

> 设置页内置「3 步生效」引导（**折叠式，点标题展开**，排在「点击跳转作者抖音」之后）：模块未完全生效时会自动出现，并在「模块状态」里指出缺哪一环（系统框架 / SystemUI），或提示「需重启手机（旧代码）」；按提示处理后点「重新检测」，全绿后引导卡自动消失。

模块会同时出现在系统设置的首页（HyperOS / MIUI 上是一行「熄屏幻术」），也可以从桌面图标进入。

## 权限

只有两个，都是普通权限：

- `VIBRATE` —— 熄屏时的触感反馈，可在设置里关掉
- `RECEIVE_BOOT_COMPLETED` —— 开机后把配置重新推送给 SystemUI，否则重启后第一次按键会用默认参数

模块不联网、不读通讯录、不申请存储权限。截图只发生在按下电源键的那一瞬间，位图用完立刻回收，不会落盘。

## 设置项

| 项目 | 说明 |
|---|---|
| 动画 | 8 种特效任选 |
| 随机特效 / 随机池 | 每次熄屏从勾选的特效里随机挑一个 |

| 锁屏音 | 保留系统原本的锁屏提示音 |

## 导出日志（反馈问题请用这个）

设置页最底部 → 点「导出日志」展开 → 点「导出日志文件」。文件落在 **文件管理 → 下载 → FadeCraft**，可以直接分享到微信 / QQ。

文件里固定包含：

- 设备信息、模块版本与构建戳、三个进程的应答情况、LSPosed 版本、当前配置
- **诊断结论**：是否被 LSPosed 拒载、作用域是否漏勾、进程是否还在跑旧代码
- **root 探测**：逐个尝试各种 `su` 调用形式，失败时连异常原文一起写进来
- **熄屏现场记录**：模块自己记的环形缓冲。logcat 通常只留得住二三十秒，这份不受影响，能看到「拦到 sleep → 抓帧结果 → 开播 → 补睡」的完整时间线
- 最近几分钟的 logcat 与 LSPosed 模块日志

**不需要 root**：系统日志由注入在 system_server 里的模块代采后回传，不用去 KernelSU / Magisk 里点授权。

正确导出的顺序：① 先在设置页点「重新检测」，等三行都变「已应答」；② 锁屏一次再解锁（让电源键那段跑一遍）；③ 点「导出日志文件」；④ 整份发出来 —— 截图看不全。

## 常见问题

**按下电源键没有动画**

先在模块设置页点一次「预览」。预览也不播，说明 LSPosed 作用域没勾「SystemUI」，或者装完模块没有重启作用域（点右上角刷新图标，或重启手机）。

**动画播了，但画面是暗色渐变、看不见屏幕内容**

这是**没抓到帧**，动画退回了兜底画面。1.0.4 及更早版本在 Xiaomi 17 / HyperOS 4（Android 17）上会稳定出现，原因是 ROM 把 system 进程的镜像抓屏权限（`ADD_MIRROR_DISPLAY` / `CAPTURE_VIDEO_OUTPUT`）收回了，建镜像虚拟屏一律抛 `SecurityException`。
**1.0.5 已修复**：改用 `IWindowManager.captureDisplay` 直接向 WindowManager 要一帧，不建虚拟屏、不碰那几个权限。更新后日志里应该是：

```
capture via IWindowManager 1220x2656 in 29ms mean=238
```

**动画播完会闪一下壁纸才黑屏**

1.0.4 及更早版本：播完后按固定延时撤黑帧，但系统从「开始灭屏」到「面板真正断电」要 400~600ms，中间就把锁屏壁纸露出来了。
**1.0.5**：改成轮询 `Display.getState()`，一直盖到状态真的变成 `OFF`；万一这次压根没熄屏，走 150ms 淡出而不是硬切。
另外 1.0.5 还处理了更慢的那条路：部分机型（HyperOS 3 / Android 16）上 system_server 主线程在熄屏一瞬被系统任务塞满，「补睡」比预计晚 1.6 秒，黑帧的宽限期会先到期。现在宽限期直接给到 9 秒（只当保险丝用），补睡的定时器在模块自己的线程上也挂了一份，迟到问题一并解决。

**指纹 / 人脸识别解锁时没有震动**

1.0.4 及更早版本：模块为了吞掉「迟到的锁屏震动」，在熄屏后开了一个长达 2.7 秒的窗口，窗口内第一次震动一律吞掉。熄屏后一秒内按指纹解锁，被吞的其实是**解锁那一震**。
**1.0.5 已修复**：窗口改成锚在「动画播完 / keyguard 真正上锁」那一刻的 700ms 窄区间，解锁时窗口早就关了。日志里可以直接验证：

```
arm haptic mute 700ms
keyguard playSound id=1 suppress=true      ← 同一瞬，锚点吻合
mute late lock haptic (vibrate) id=1000     ← 被吞的是锁屏那一下
```

**动画播到一半黑屏**

通常是时长参数拉得太长、超过了系统兜底睡眠的时间。把时长调回 1 秒以内。

**锁屏音响了两次**

系统自己的锁屏音和模块补的那一声重叠了。在设置里关掉「锁屏音」，或者把抑制窗口的时长调大（模块会自动按动画真实时长调整）。

**熄屏时手机震了两次**

系统那一下「迟到的」锁屏震动没被吞掉。它本该和按键同时，但因为动画把睡眠推迟了整整一个时长，就变成动画结束后再震一次。模块会在动画播完那一刻开一个 900ms 的窄窗口把它吞掉 —— 这个窗口和设置里的「震动反馈」开关**无关**：开关管的是「模块要不要替你补一下」，窗口管的是「动画造成的重复震动」，两者分开。

如果仍然震两次，看导出日志里有没有这两行：

```
arm haptic mute 900ms
mute late lock haptic (vibrate) id=...
```

只有第一行、没有第二行，说明窗口开了但系统那一下来得更晚或走了别的通道，把整份日志发出来即可定位。

**升级后完全没反应**

同一个版本号短时间内反复覆盖安装，LSPosed 的 dex 缓存可能不刷新。重启一次手机即可。

**LSPosed 里明明「已启用」、作用域也勾了，还是没效果**

先看设置页顶部的「模块状态」：显示「运行中」才是真的注入进去了。如果一直「未响应」，去看 LSPosed 自己的日志（`/data/adb/lspd/log/verbose_*.log`）里有没有：

```
E/LSPosedFramework: Cannot load module: io.github.lubenjian88.fadecraft
E/LSPosedFramework: The Xposed API classes are compiled into the module's APK.
```

这两行意味着模块包把 Xposed API 类打包进了 dex，LSPosed 会直接拒绝加载 —— 管理器界面照样显示「已启用」，但一行 hook 都进不去。**1.0.3 已修复**（stub 只参与编译、不再进 dex），更新到这个版本即可。

**设置首页没有「熄屏幻术」这一行**

这一行是注入进去的，需要在 LSPosed 作用域里勾上「系统设置」。只勾「SystemUI」和「系统框架」时动画照常工作，只有这一行不出现 —— 设置页顶上的「模块状态」会显示「运行中（设置待激活）」。

注意「设置待激活」不一定是没勾：系统设置进程只有被打开时才活着，没打开过就回不了话。**打开一次系统设置，回到模块页点「重新检测」**即可转绿；如果还是不变，再去 LSPosed 补勾作用域。

**和别的模块冲突**

同时改 SystemUI 电源键/熄屏流程的模块（比如某些手势模块）可能互相抢 hook。先停用其他模块逐个排查。

## 支持的设备与系统

### 已验证（开发机）

- **Xiaomi 13**（代号 fuxi，型号 2211133C）｜HyperOS 4.0.5.0（**Android 17 / API 37**）｜KernelSU + LSPosed 2.2.1
- **Xiaomi 17**（代号 popsicle，型号 2509FPN0BC）｜HyperOS 4.0.0.43（**Android 17 / API 37**）｜LSPosed 2.2.1
  - 这台是抓帧问题最严重的机器：1.0.4 及更早版本五条抓帧路径全灭，只能播兜底暗色；**1.0.5 起正常**。

### 系统要求

- **Android 10（API 29）及以上**；开发验证环境为 **Android 17（API 37）/ HyperOS 4**
- 模块 APK 当前 **targetSdk 34**（在更高版本的系统上以兼容模式运行，功能正常）
- 必须已 **Root**，并安装 **LSPosed**（Magisk / KernelSU / APatch 任一方案均可）
- 作用域**至少勾选「SystemUI」**——这是动画能出现的前提，缺一不可

### 按 ROM 区分

| ROM 类型 | 熄屏动画 | 设置首页入口 | 说明 |
|---|---|---|---|
| HyperOS / MIUI | ✅ | ✅ | 完整支持，设置首页多出一行「熄屏幻术」，桌面图标与设置入口可二选一 |
| 原生 AOSP / 类原生（Pixel、LineageOS 等） | ✅ | ❌ | 核心动画可用；「设置首页入口」依赖 MiuiSettings 注入点，这类 ROM 上不出现，可从桌面图标 / LSPosed 进入设置 |
| 其它深度定制 ROM（ColorOS、OriginOS、One UI 等） | ⚠️ 未逐一验证 | ⚠️ | 截屏走 `SurfaceControl`、窗口用 `TYPE_DISPLAY_OVERLAY`，理论上可用；若动画不出现，尝试在作用域额外勾选「系统框架」 |

### 按机型

- 模块逻辑与**具体机型无关**，只要系统满足上面的 Android 版本与 Root 条件即可
- 折叠屏 / 多屏设备**未专门适配**，横竖屏切换、多窗口下可能表现不一致
- 分辨率、刷新率不影响运行，但高刷屏上动画更顺滑

## 注意事项

1. **必须 Root + LSPosed，且作用域勾选「系统框架 / SystemUI / 系统设置」**——动画与设置入口能正常工作的前提，缺一不可（只勾 SystemUI 时电源键拦截不会生效）。
2. **覆盖安装 / 更新 APK 后必须整机重启手机**：模块的核心逻辑跑在 system_server 里，而应用内的「重启作用域」只重启 SystemUI + 系统设置、碰不到 system_server，所以**只点「重启作用域」时电源键动画不会生效**；只有整机重启才能让 system_server 重新加载模块。更新之后再改 SystemUI / 设置相关的参数，才可以用「重启作用域」即时生效。
3. **动画时长不要超过 1 秒**：过长会撞上系统兜底睡眠，表现为「播一半就黑屏」，把时长调回 1 秒内即可。
4. **避免和其它改电源键 / 熄屏流程的模块同开**：某些手势、防误触、双击熄屏模块会和本模块抢同一个 hook，冲突时先停用其它模块逐个排查。
5. **省电模式下默认跳过动画**：这是预期行为，不是 bug，可在设置里关掉「省电模式不播放」。
6. **不联网、不落盘**：截屏只发生在按下电源键那一瞬间，位图用完立即回收，不会写入存储，也没有任何网络请求。
7. **升级后完全没反应**：大概率是 LSPosed 的 dex 缓存没刷新，重启一次手机即可。
8. 反馈问题时请附上：**机型、系统版本、LSPosed 版本**，以及设置页最底部「导出日志」生成的那份 txt（整份发，别截图）。
